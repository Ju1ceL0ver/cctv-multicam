# Трекер door_seg, 10.10.2026

`multicam/door_seg_track.py` принимает ответы `door_seg.predict`: маска шага 4,
рамка в пикселях 1280×736, уверенность и смещения к t−1/t+1. На соседних
тактах проверяет обе стороны связи и перекрытие сдвинутых масок; назначение
взаимно однозначное, с возможностью отказаться от связи. При спорных парах
создаёт новый номер. Через пропуск до 25 тактов (2 с) использует наблюдавшуюся
скорость, а не умножает однокадровые смещения. Без детекции маску не выдаёт.
Пороги и веса — начальная конфигурация; точность на записях ещё не измерена.
Внешность владелец разрешил, но в текущем чекпоинте головы отпечатка нет.

## Запуск после завершения обучения

На Windows из `C:\Users\ArykovAA\cctv_ai\multicam`, среда `venv_sam3`:

```text
python door_seg_run.py runs/doorseg_b/stepNNNN.pt doorseg_track_b1 20260917 20260918 20260919
```

Выбрать лучший проверенный чекпоинт; `NNNN` здесь обозначает его шаг.
Для короткой пробы добавить `--tags door_20260918_18720`.
Имя запуска должно быть новым: существующий эксперимент не перезаписывается.
Все такты 12.5 fps обрабатываются, включая края видео. Входная маска t−1 —
собственный предыдущий ответ. Учитель не используется для связи или подсказки
масок. Видео читается последовательно с буфером ±5, контекст на краях повторён.

Результаты: `data/micro_door/ИМЯ/<отрезок>/cam1/{chunks.npz,info.json,report.json,ticks.json}`,
`data/door_v2/<день>_ИМЯ.jsonl.gz`. Формат совместим с `door_binary_count`,
`door_compare_video`, `door_sam.convert`. Номера не сшиваются между независимыми
дверными отрезками; внутри отрезка сброса по сессиям нет.

Сначала получить ответы модели стороны и глубины существующими CPU-скриптами
с `RA_BIN_SRC=ИМЯ`. Сравнение делать на `done`-отрезках `/doorside` с ролью
`test` (нет роли — тоже `test`), отдельно от `train`. Параметры трекера на
проверочных отрезках не подбирать. Полная серия старых 22 отрезков — отдельная
сравнительная цифра, а не автоматически независимый тест новой модели.

Скорость в `info.json` включает декодирование, подготовку входа, сегментацию,
трекинг и экспорт масок; это не чистая скорость модели. Под обучением скорость не замерять.
Этот запуск не запускает обучение, живую дверь или CRM и ничего не публикует.

Проверка плато второй серии: три учтённые оценки без прироста ≥0.5 п. п.,
разнесённые минимум на 2000 шагов (раздел 64 AGENTS). Плато позволяет завершить
обучение; для перехода в бой дополнительно нужны превосходство над текущей
дверью на общей проверочной выборке и достаточная скорость, затем уведомление
владельца. 0.935 из старого отчёта нельзя напрямую сравнивать с другой выборкой.

Проверка кода: `python -m pytest -q tests/test_door_seg_track.py` — 11 тестов.
Они проверяют механику; качества на реальных людях не доказывают.

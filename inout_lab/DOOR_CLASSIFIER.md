# Камера 1: внутри / снаружи / в проёме

Готовые файлы: `door_classifier.py`, `door_features.py`, `door_ensemble.py`, `inside_outside.py`, `door_classifier.pkl`.
Зависимости: numpy, scipy, opencv-python, scikit-learn. Классификатор работает на CPU, GPU не нужен. Объединены лес и градиентный бустинг на тех же признаках.

```python
from door_classifier import DoorClassifier
import cv2

model = DoorClassifier(threshold=0.9)
rgb = cv2.cvtColor(cv2.imread('frame.jpg'), cv2.COLOR_BGR2RGB)
mask = cv2.imread('person.png', cv2.IMREAD_GRAYSCALE)  # маска одного человека
result = model.predict_rgb(rgb, mask)
print(result)
```

`label`: inside / outside / doorway / unknown. `raw_label`: исходный класс до порога. `confidence`: оценка леса, не гарантия правильности. Для ответов на каждом кадре задайте `threshold=0`, но тогда останутся грубые ошибки. `unknown` не считать входом или выходом. Модуль не содержит трекинг или накопление: нельзя выдавать качество классификации за качество счётчика.

Передавайте исходные `box` и `foot` трекера, если доступны: это помогает совпадению с обучением при перекрытиях. Они должны быть в пикселях исходного кадра. Изображение — RGB uint8; маска ненулевыми значениями выделяет одного человека. Ракурс только камеры 1. Полигон пола сохранён внутри модуля, свободный пол используется как признак, не как готовый ответ о стороне двери.

Проверка по дням: каждый предсказанный день исключался из обучения. Все 190 примеров «в проёме» сохранены; 47 «не понять» не имеют целевого класса и исключены. На 1581 определённом примере: 93,99%, 95 ошибок; грубых inside↔outside 4 вместо прежних 15. Подбор вариантов проведён по этим же дням, это диагностическая оценка, не новый слепой тест.

При пороге 0,9 наблюдается 0 грубых ошибок среди определённых ответов, но покрытие составляет только 78,94% всех примеров и 67,85% примеров у двери. Поэтому задача полностью не решена: отказы и остальные ошибки необходимо считать отдельно, а ноль на просмотренной выборке не гарантирует ноль на новых кадрах. Итоговый файл обучен на всех определённых примерах, не применять его для повторной независимой оценки этих же данных.

Сводка размера и времени: `door_classifier_report.json`. Галерея всех оставшихся ошибок, первыми грубые: `door_errors.html`. Метки не менялись. Воспроизведение: `head_features_search.py`, `context_features_search.py`, `package_door.py`. Подготовленные признаки новой реализации совпадают с исследовательским экспортом точно на 96 примерах.

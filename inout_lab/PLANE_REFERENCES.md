# Какие плоскости отметить

Используйте один исходный кадр камеры 1 и реальные известные размеры.
Шаблон — `plane_reference_template.json`; null означает, что размер ещё неизвестен,
а не значение, которое агенту разрешено угадать.

Для каждой плоскости отметьте четыре соседних угла по кругу: P0, P1, P2, P3.
Первый размер — реальная длина P0→P1, второй — P1→P2, в метрах.
На полу можно взять прямоугольник из нескольких целых плиток. Вертикальная
опора — неподвижная рама, прямоугольная панель или участок стены; не открытая створка.
Углы должны быть углами одного настоящего прямоугольника, а не его общей рамкой на экране.

`image_size_px` — размер изображения, на котором отмечались координаты.
Для исходных JPEG в этом наборе это обычно1280×720. Если рисунок сделан на
уменьшенном скриншоте, нужны его размеры и отсутствие обрезки. Текущий K
описан для2560×1440; инструмент масштабирует его к указанному кадру.

Полезно отметить ещё 1–3 независимые точки той же плоскости: например,
пересечения плиточных швов с известными координатами относительно P0.
Формат `check_points`: `{"plane_xy_m":[0.6,0.3],"image_px":[420,510]}`.
Пример координат объясняет формат и не является измерением магазина.

Запуск изinout_lab существующим ML Python:

```sh
/opt/homebrew/Caskroom/miniforge/base/bin/python plane_reference.py measured_planes.json --out measured_plane_result.json
```

Результат содержит перпендикулярное расстояние камера–плоскость, расстояние
до центра прямоугольника, ошибки проекции углов/контрольных точек и плотность
пикселей на квадратный метр **этой плоскости**. При близких двух planar-PnP
решениях неоднозначность остаётся явно помеченной.

Это использует существующие intrinsics/distortion как предположение. Их ещё
нужно проверить на реальном кадре и независимых линиях. Несвязанные floor/wall
прямоугольники решаются в разных локальных системах: общая3Dсцена пока не строится.
Расчёт не определяет автоматически расстояние до человека, который не лежит
на отмеченной плоскости. Для этого нужны положение на полу/высота/другая опора.

Локальная страница `plane_annotator.html` позволяет выбрать четыре угла,
ввести известные стороны в метрах и скачать `measured_planes.json` для команды
выше. Отдельные плоскости переключаются в списке; исходный кадр можно заменить.
Экспортируются только заполненные выпуклые четырёхугольники с положительными
размерами. Страница не отправляет данные на сервер и не оценивает расстояние.

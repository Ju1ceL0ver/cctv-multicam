# Средние координаты, отдельные каналы и kNN

Все три класса сохранены. На кадре 1280×720 средний **центр видимой маски**:

| Класс | x | y | Примеров |
|---|---:|---:|---:|
| снаружи | 387.76 | 178.92 | 681 |
| внутри | 563.23 | 312.12 | 710 |
| в проёме | 366.15 | 231.18 | 190 |

В `spatial_means.json` также есть средние для верхних 15% видимой маски и исходной точки ног трекера. Это разные точки; верхняя часть маски не обязательно анатомическая голова, точка ног при перекрытии может оказаться на стойке.

`spatial_prior.py`: `SpatialPrior.fit(A, y)` оценивает средние и ковариации. `channels()` выдаёт H×W×3 карты нормированной гауссовой пространственной плотности классов. Плотности учитывают разброс, а не только расстояние до среднего. Это признаки, не гарантия стороны и не физическая граница двери. Карты привязаны к ракурсу камеры 1. При аугментациях зеркалить/поворачивать их вместе с изображением и маской.

```python
from door_classifier import DoorClassifier

model = DoorClassifier('door_spatial_means.pkl', threshold=0)
maps = model.model.prior.channels()  # 180x320x3; outside, inside, doorway
means = model.model.prior.summary()
# Обычный API: RGB uint8 и маска одного человека
result = model.predict_rgb(rgb, person_mask)
```

Деревья используют значения пространственных карт в точках человека и расстояния до средних; это не обучение свёрточной сети. Для настоящих дополнительных каналов есть отдельный `spatial_cnn.py`: RGB + маска + пол + x/y + три карты = 10 каналов; три блока 64/128/256, полносвязные 256/64/3. Сравнивает baseline, maps и maps_knn на одном исключённом дне. Использует маску для выбора признаков целевого человека среди других людей в кадре. В maps_knn добавляется 144 геометрических признака, включая расстояния до средних и голоса ближайших соседей.

kNN использует верх маски, центр, исходную точку ног и совместную геометрию; соседей 3/9/25/61, голос взвешен по расстоянию. `metric_knn_search.py` дополнительно проверяет контекст пола/цвета и обученную метрику NCA.

**Защита от утечки:** при проверке дня его метки исключены из всех средних, карт и соседей. Для тренировочных строк карты/соседи тоже строятся по другим дням (вложенный cross-fitting), иначе kNN подсказывает строке её собственную метку. Входные RGB/маски остаются исходными, метки не изменены. Итоговые карты в spatial_channels.npy/.png обучены на всех определённых примерах и не используются для независимой проверки тех же данных.

Проверка по всем девяти дням (подбор по этим же дням; не новый слепой тест):

| Вариант | Точность 3 классов | Грубых внутри↔снаружи |
|---|---:|---:|
| прежний RGB-контекст: лес | 93.55% | 6 |
| прежний RGB-контекст: лес + бустинг | 93.99% | 4 |
| лес + средние/карты | 93.80% | 4 |
| лес + средние + kNN | 93.42% | 10 |
| только пространственный kNN | 89.37% | 34 |
| kNN с контекстом и PCA | 91.02% | 13 |
| kNN с контекстом и обученной метрикой | 91.52% | 12 |

Текущий `door_classifier.pkl` не заменён более слабым вариантом. Экспериментальные готовые веса: `door_spatial_means.pkl`, `door_spatial_means_knn.pkl`. Результаты CNN отдельно в `spatial_cnn_20260918_report.json` после завершения сравнения. Ни один вариант нельзя объявлять идеальным по этой диагностике.

Воспроизведение: `python spatial_search.py`, `python package_spatial.py`, `python metric_knn_search.py`, `python spatial_cnn.py --day 20260918 --epochs 30`.

Запуск сохранённой CNN (веса исключают 18.09, это экспериментальная модель):

```python
from spatial_cnn_predictor import SpatialCNNPredictor

model = SpatialCNNPredictor(
    'diagnostics/spatial_cnn_20260918_maps.pt', threshold=0, device='mps'
)
result = model.predict_rgb(rgb, person_mask)
```

`spatial_cnn_predictor.py` загружает соответствующий `spatial_cnn_prior_excluding_20260918.pkl` автоматически. Карты для этой модели построены без 18.09; подменять их картами, рассчитанными по всем дням, нельзя. При доступности передавайте исходные box/foot трекера для совпадения геометрии при перекрытиях.

На 8-ГБ Маке обновлённый загрузчик держит на MPS только текущий батч. `cnn_frames_88x160.npy` создаётся один раз как файл с отображением в память, float32; resize побитово совпадает с исходным. Gaussian-карты хранятся по одной на обучающий fold, вместо одинаковой копии для каждого человека. Если исходный NPZ изменится, кеш пересоберётся по размеру и mtime. Это уменьшает давление на память без изменения признаков.

Завершённый CNN-прогон на 18.09: 313 определённых примеров, все 62 с меткой «в проёме» сохранены; 18.09 исключён из обучения и всех priors. Одинаковые seed=0, 30 эпох, RGB-аугментации, целевые пулы маски и архитектура во всех вариантах:

| CNN | Точность | Всех ошибок | Грубых внутри↔снаружи |
|---|---:|---:|---:|
| без новых карт | 80.51% | 61 | 3 |
| три карты дополнительными каналами | 84.03% | 50 | 4 |
| три карты + признаки kNN | 82.75% | 54 | 6 |

Карты помогли общей точности в этом прогоне, но не убрали грубые ошибки. kNN ухудшил результат; в рабочую модель он не включён. Это один seed на уже исследованном тяжёлом дне, не доказательство общего выигрыша CNN. Все обученные веса сохранены отдельно в diagnostics. Новая память-экономная загрузка добавлена после этого прогона; численные входы проверены на точное совпадение с исходным resize.

Проверка загрузки сохранённых весов пройдена для всех трёх CNN: вероятности совпадают с записанной оценкой (максимальная разница 1.2e-7), API RGB+маска работает. На MPS подготовленный пример: baseline ~9.5 мс, карты ~8.5 мс, карты+kNN ~46.2 мс; это без сегментации и полного RGB-препроцессинга. Измерение короткое, времена диагностические. Подробности `spatial_cnn_inference_report.json`.

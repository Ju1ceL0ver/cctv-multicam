# Камера 1: экспериментальный лёгкий классификатор

Цель без грубых перепутываний пока не достигнута. Новый минимум — **1 грубая
ошибка / 1581 определённый пример**, индекс393 (`inside → outside`).
Всего117 ошибок, accuracy92.60%. Это диагностический leave-one-day-out на
девяти уже исследованных днях, не свежий слепой тест. Все190 doorway сохранены,
исключены только47 исходных unknown. Модель всегда возвращает один из трёх
классов; порога отказа или подмены uncertain на doorway нет.

| Истина / ответ | outside | inside | doorway |
|---|---:|---:|---:|
| outside |660|0|21|
| inside |1|688|21|
| doorway |39|35|116|

Прежний depth-ансамбль давал102 ошибки/2 грубые. Новый вариант уменьшает
прямую путаницу сторон ценой15 дополнительных ошибок остальных типов.
Рабочие веса и службы Windows/CRM не заменены.

## Файлы

- `recovered_classifier.py`: RGB+маска → outside/inside/doorway.
- `recovered_classifier.pt`: отдельный refit на всех1581 определённых строках,
  512073 параметра,2098358 байт. Это веса для применения; их нельзя оценивать
  на обучавшихся строках как новый тест.
- `owner_boundary_mlp_recovered_report.json`: честные по исключению дня прогнозы.
- `owner_boundary_mlp_recovered_audit.json`: независимое воспроизведение всех9
  сохранённых исключённых дней, проверка отсутствия их в train и нормировке.
- `recovered_classifier_api_audit.json`: паритет RGB+маска с сохранёнными
  прогнозами исключённых дней для393/970/1149/1394 и измерение скорости.
- `recovered_crop_features_report.json`, `diagnostics/recovery_report.json`:
  проверка происхождения новых вырезок и неизменности меток.

На Mac в проверке во время другого обучения: median26.70ms / p90 28.42ms на
одного человека изRGB1280×720+маски, CPU,1torch thread. Сегментация и чтение
файла в это время не входят. Не измерение скорости всего счётчика/двух камер.
Инференс не использует YOLO-pose, глубину или будущие кадры.

## Пример

Использовать существующий ML Python; новые пакеты не требуются.
Из каталога `inout_lab`:

```python
import cv2
import torch
from recovered_classifier import RecoveredClassifier

torch.set_num_threads(1)
model = RecoveredClassifier()
rgb = cv2.imread("diagnostics/api_970_rgb.png")[:, :, ::-1].copy()
mask = cv2.imread("diagnostics/api_970_mask.png", 0)
answer = model.predict_rgb(rgb, mask)
print(answer)
```

`frame` — RGB uint8, маска одного человека того же размера, ненулевой пиксель
означает человека. Камера только1. При наличии передавать исходные
`box=[x1,y1,x2,y2]` и `foot=[x,y]` трекера в пикселях входного изображения;
`floor_px` — расстояние до прежней маски свободного пола в системе1280×720.
Они необязательны: API вычислит их, но именно исходные метаданные использовались
при проверке паритета сNPZ. Это видимые точки, а не обещание истинных ступней.

`predict_prepared(full,crop,geometry,original_geometry)` принимает уменьшенный
полный кадр180×320 сRGB/маской/полом и вырезку160×96 из исходных пикселей,
девять геометрических признаков без номера камеры. Координаты ног в полном
G исходногоNPZ — G[:,7:9], после удаления номера камеры — g[:,6:8].

## Что изменилось

Исправленная рамка определяется по видимой маске, ноRGB вырезается заново из
исходного изображения. Старые уменьшенные вырезки не растягиваются.
Для всех1628 строк на Windows точно воспроизведены все7каналов полногоF
исходногоNPZ; y,ids,day и координаты ног не менялись. Признаки изменились у1620
строк за счёт восстановленных пикселей и корректной вырезки.

MLP объединяет геометрию, форму маски иRGB. Геометрия включает признаки
относительно размеченного владельцем порога и несколько гипотез высоты;
не использует размер плитки в метрах. Новая калибровка по швам не принята,
исходные параметры не заменены. Диагностическая нормаль швов используется
лишь как дополнительная гипотеза признаков рядом со старой нормалью.

В прогнозах исключённых дней393 остаётся грубой ошибкой;1149 и1394
отвечаются какdoorway вместо правильной стороны. Выход confidence — некалиброванный score сети. Веса и API локальные,
в боевую систему не включены; соответствие live-масок видимым draft-маскам
нужно проверять при интеграции.

# Маленькая CNN: полный кадр и детальная вырезка

Эксперимент камеры1, три класса: outside / inside / doorway. Проверяемый день полностью исключается из обучения. Взвешенная cross-entropy, без выкидывания doorway и без unknown вместо ответа.

Один общий кодировщик из трёх блоков Conv3×3 + BatchNorm + ReLU + MaxPool2×2, каналы64/128/256, применяется к двум видам одного наблюдения:

- полный кадр: RGB, маска выбранного человека, область пола, абсолютные x/y;
- детальная вырезка: те же семь каналов, сохраняющая мелкие детали человека.

С каждого вида берутся сетка2×2, среднее по целевой маске и среднее её верхней части. Добавляются9 геометрических признаков. Затем три полносвязных слоя256/64/3. Замороженного или предобученного кодировщика нет. Для обеих картинок согласованы фотометрические аугментации. Minibatch24, file-backed cache полного кадра, вырезкиuint8; весь датасет наMPS одновременно не переносится.
